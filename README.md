# Kitten Planner 🐾

Личный рабочий дашборд для Windows: заметки, планы и задачи, календарь, чат с ChatGPT и маленький котёнок,
который бегает за курсором и играет с карточками.

Все данные хранятся **только локально** — в папке `%APPDATA%\Kitten Planner` (`data.json`).
API-ключ OpenAI хранится отдельно и зашифрован средствами Windows (DPAPI).

## Скачать

Готовый `.exe` — во вкладке **Releases** или в артефакте `KittenPlanner-windows` последней сборки во вкладке **Actions**.
Установка не нужна: это портативная программа, просто запустите файл.

## Возможности

- **Главная** — задачи на сегодня, ближайшие события, прогресс планов, последние заметки.
- **Планы и задачи** — планы-цели с прогрессом, задачи со сроками и приоритетами, фильтры.
- **Календарь** — месяц, события с временем и цветом, задачи со сроком на дне.
- **Заметки** — поиск, цвета, закрепление, автосохранение.
- **ИИ-помощник** — чат с ChatGPT (свой API-ключ), несколько разговоров, учитывает ваши планы, ответ можно сохранить в заметки.
- **Котёнок** — бегает за курсором, засыпает, если мышь не двигается, мурлычет, если подержать на нём курсор, иногда толкает кнопки и карточки. Отключается в настройках.
- Экспорт/импорт резервной копии.

## Разработка

```bash
npm install
npm start            # запуск
npm run check        # линтер + форматирование + юнит-тесты
xvfb-run -a npx playwright test   # e2e (на Linux)
npm run dist:win     # сборка .exe (на Windows)
```
